# 🏨 Aplikasi Reservasi Hotel

## 📌 Deskripsi
Aplikasi Reservasi Hotel adalah aplikasi berbasis desktop yang dibuat menggunakan **Visual Basic .NET (VB.NET) dengan Windows Forms** dan **Microsoft SQL Server** sebagai database.

Aplikasi ini dirancang untuk membantu proses pengelolaan data hotel, mulai dari data tamu, data kamar, reservasi, hingga pembayaran. Dengan aplikasi ini, pengelolaan informasi hotel menjadi lebih mudah, terstruktur, dan efisien.

## ✨ Fitur Aplikasi
- **Login:** Mengatur akses pengguna ke dalam aplikasi.
- **Menu Utama:** Menampilkan navigasi ke setiap fitur aplikasi.
- **Data Tamu:** Menambah, mengubah, menghapus, dan menampilkan data tamu.
- **Data Kamar:** Mengelola informasi kamar, tipe kamar, harga, dan status kamar.
- **Reservasi Hotel:** Mengelola pemesanan kamar berdasarkan data tamu dan kamar.
- **Pembayaran:** Mengelola transaksi pembayaran berdasarkan data reservasi.

## 🛠️ Teknologi yang Digunakan
- Visual Studio 2022
- Visual Basic .NET (VB.NET)
- Windows Forms
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## 🗄️ Database
Nama database: `db_hotel2`

Tabel yang digunakan:
- `users`
- `tamu`
- `kamar`
- `reservasi`
- `pembayaran`

## 🚀 Tujuan Pengembangan
Proyek ini dibuat sebagai media pembelajaran untuk menerapkan pemrograman desktop, pengelolaan database, serta konsep CRUD (Create, Read, Update, Delete) dalam sebuah aplikasi reservasi hotel.

## 👨‍💻 Pengembang
Dikembangkan sebagai proyek pembelajaran menggunakan Visual Basic .NET dan SQL Server.
